# keeltrading.com — the public website for Keel

This repository holds the public website for [Keel](https://github.com/CodeGateSoftware/keel),
the open-source, auditable Shariah-compliance engine for spot-crypto and equities trading.

The site is a **read-only presentation layer over GitHub**: plain-English explanations,
documentation rendered from the engine repository, news from GitHub Discussions, and
download buttons pointing at GitHub Releases. Community interaction (posting, voting,
polling) stays on GitHub — the site surfaces and translates, it never duplicates.

**Status: specification stage.** The scope, decisions, and delivery plan live in
[`docs/superpowers/specs/2026-08-19-website-prd.md`](docs/superpowers/specs/2026-08-19-website-prd.md).
Work is tracked on the `Phase 15 — Public website v1` milestone.
